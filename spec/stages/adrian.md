# 아드리안 · 대기 샘플

## 항로와 도착 장면

- `지구 기준 · 타우 세티까지 약 11.9광년`을 표시한다. 작품 속 아드리안의 행성 모습과 샘플은 창작 재현이다.
- 계기판 위 좁고 직사각형인 관측창에서 층이 있는 구름과 황회색 대기를 본다. 도착 후 화면 아래쪽에는 탐사선이 줄에 연결되어 있고, 화면 위쪽에 샘플 상태를 표시한다.

## 조작과 상태

| 상태 | 조작 | 피드백과 다음 상태 |
| --- | --- | --- |
| 준비 | `탐사선 내리기` | 3초 동안 탐사선이 구름으로 내려간다. `채취 고도에 도달하는 중`을 표시한다. |
| 채취 | 하강 완료 시 자동으로 2초 채취 | 탐사선의 시료 용기에 입자가 모인다. 완료 시 `샘플 채취 완료`와 `샘플 관찰`을 보여준다. |
| 확대 관찰 | `샘플 관찰`을 누른 뒤 확대 슬라이더 1×–4× | 3×부터 움직이는 미생물 형상과 `미생물 형상 관찰` 표시가 나타난다. |
| 완료 | 3× 이상을 한 번 확인한 뒤 `탐사 기록 보기` | `대기 샘플을 채취하고 확대해 미생물 형상을 관찰했다.`와 실제 처음 확인한 배율을 기록한다. |

- 샘플 관찰을 열 때 배율은 1×다. 0.5× 단위로 조절한다. 모션 감소에서는 미생물의 움직임 대신 같은 형상을 정지 상태로 보여준다.
- 화면에는 `작품을 바탕으로 재현한 샘플`을 표시한다. 확대를 낮추면 미생물 형상이 사라지고 관찰 완료 상태는 유지한다.
- 항로에서는 공기음이 낮게 깔리고, 채취 완료를 짧은 진동음과 상태 문구로 알린다.

## 검수

- 하강과 채취가 끝나기 전 확대 관찰이 열리지 않는다. 시작 버튼을 연속 입력해도 탐사선과 타이머는 각각 한 번 시작한다.
- 2.5×에서 완료 버튼은 잠겨 있고 3×에서 열린다. 4×로 바로 올리면 기록의 첫 확인 배율은 4×다.
