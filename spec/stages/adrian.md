# 아드리안 · 페트로바 선과 대기 샘플

## 항로와 도착 장면

- `지구 기준 · 타우 세티까지 약 11.9광년`을 표시한다. 작품 속 아드리안의 행성 모습과 샘플은 창작 재현이다.
- 계기판 위 좁고 직사각형인 관측창에서 층이 있는 구름과 황회색 대기를 본다. 도착 후 화면 아래쪽에는 탐사선이 줄에 연결되어 있고, 화면 위쪽에 샘플 상태를 표시한다.

## 항로 조작 · 페트로바 선

자동 비행의 70% 지점에서 관측창의 가시광선 화면과 적외선 의사색 화면을 비교한다. 적외선에서 타우 세티와 아드리안을 잇는 밝은 띠가 드러난다. `페트로바 선 따라가기`를 선택하면 비행을 재개하고 띠가 닿은 지점에서 탐사선을 내릴 수 있다. 필터와 비행 위치는 저장된다.

## 조작과 상태

| 상태 | 조작 | 피드백과 다음 상태 |
| --- | --- | --- |
| 준비 | `탐사선 내리기` | 3초 동안 탐사선이 구름으로 내려간다. `채취 고도에 도달하는 중`을 표시한다. |
| 채취 | 하강 완료 시 자동으로 2초 채취 | 탐사선의 시료 용기에 입자가 모인다. 완료 시 `샘플 채취 완료`와 `샘플 관찰`을 보여준다. |
| 확대 관찰 | `샘플 관찰`을 누른 뒤 확대 슬라이더 1×–4× | 저배율에서 보이는 희미한 입자가 확대되면서 움직이는 미생물의 윤곽이 선명해진다. 3×부터 `미생물 형상 관찰`을 표시한다. |
| 완료 | 3× 이상을 한 번 확인한 뒤 `탐사 기록 보기` | `대기 샘플을 채취하고 확대해 미생물 형상을 관찰했다.`와 실제 처음 확인한 배율을 기록한다. |

- 샘플 관찰을 열 때 배율은 1×다. 0.5× 단위로 조절하며 배율과 선명도가 약 200ms에 걸쳐 바뀐다. 모션 감소에서는 배율이 즉시 바뀌고 미생물은 정지 상태로 보인다.
- 화면에는 `작품을 바탕으로 재현한 샘플`을 표시한다. 배율을 낮추면 같은 미생물이 작고 흐릿하게 보이며 관찰 완료 상태는 유지한다.
- 항로에서는 공기음이 낮게 깔리고, 채취 완료를 짧은 진동음과 상태 문구로 알린다.

## 탐사 기록

탐사 기록에는 적외선에서 발견한 페트로바 선이 이곳에서 채취한 이유였다는 점, 처음 미생물 형상을 확인한 배율, `작품을 바탕으로 재현한 샘플`을 표시한다.

작품 속 해설은 타우 세티의 밝기가 유지된 이유를 아스트로파지와 포식자의 관계로 설명한다. `현실과 비교`에서는 제임스 웹 우주망원경의 적외선 관측과 연결하고, 탐사의 적외선 의사색과 화면 확대가 어떤 정보를 보여 주는지 밝힌다. [NASA 적외선 천문학](https://science.nasa.gov/mission/webb/science-overview/science-explainers/infrared-astronomy/)

## 검수

- 가시광선에서는 띠가 보이지 않는다. 적외선으로 전환해 띠의 끝을 선택한 뒤에 접근을 계속할 수 있다.
- 하강과 채취가 끝나기 전 확대 관찰이 열리지 않는다. 시작 버튼을 연속 입력해도 탐사선과 타이머는 각각 한 번 시작한다.
- 2.5×에서 완료 버튼은 잠겨 있고 3×에서 열린다. 4×로 바로 올리면 기록의 첫 확인 배율은 4×다.
