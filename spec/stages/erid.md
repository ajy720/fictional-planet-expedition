# 에리드 · 반향과 세 음의 교신

## 항로와 도착 장면

- `지구 기준 · 에리다누스자리 40 항성계까지 약 16광년`을 표시한다. 에리드 관측 장면은 작품의 반향 감각을 바탕으로 재현한다.
- 조종석에는 낮고 긴 관측창과 옅은 호박색 내부 빛을 사용한다. 도착 시 거의 어두운 공간에 세 물체를 놓는다. 왼쪽의 낮은 바위, 중앙의 아치, 오른쪽의 기둥을 서로 겹치지 않도록 배치한다.

## 조작과 상태

1. `음파 보내기`를 누르면 화면 아래 중앙의 송신기에서 파면이 퍼진다. 한 회차가 끝나면 `음파 다시 보내기`가 활성화된다. 교신에 답하는 중이나 교신이 끝난 뒤에도 다시 보낼 수 있다.
2. 파면이 물체에 닿으면 접촉점에서 윤곽이 드러나고, 각각의 반사파가 송신기 쪽으로 퍼진다. 반사파가 송신기에 도달할 때 수신 개수와 물체명을 갱신한다. 소리를 켜면 같은 순간에 해당 방향에서 짧은 반향음이 들린다.
3. 첫 관측이 끝나면 낮은음 → 높은음 → 중간음의 교신이 들어온다. 수신한 음의 높이를 막대와 글자로도 보여준다. 소리를 켰을 때는 신호를 다시 들을 수 있다. 음파를 다시 보내도 입력한 응답과 교신 완료 상태가 유지된다.
4. 낮은음, 중간음, 높은음 버튼으로 응답한다. 순서가 어긋나면 첫 음부터 다시 보낸다. 같은 세 음을 보내면 상대가 답하고 기록 버튼이 열린다.
5. 기록에는 세 물체의 윤곽, 응답한 음의 순서, 에리드의 음성 언어를 바탕으로 구성한 체험용 신호라는 설명을 남긴다.

- 장면의 거리가 멀수록 반향의 왕복 시간이 길다. 파면에는 체험용 음속을 사용한다.
- 모션 감소 모드에서는 파면이 물체에 닿는 순간 정지 윤곽을 표시한다. 음소거 상태에서도 화면으로 같은 물체, 수신 순서, 완료 상태를 확인할 수 있다.

## 관찰 기록 해설

에리드인이 주변을 감지하는 데 사용하는 반향과 음높이 조합으로 뜻을 전달하는 의사소통 방식을 설명한다. `현실과 비교`에서는 음속과 왕복 시간으로 거리를 구하는 방법과 사람의 반향정위 실험을 소개한다. [Thaler 외 (2019), 사람의 반향 거리 지각](https://pmc.ncbi.nlm.nih.gov/articles/PMC6797687/)

## 검수

- 음파를 보내기 전에는 물체의 이름과 윤곽이 보이지 않는다. 바위, 아치, 기둥에 닿은 반사파가 차례로 송신기에 돌아온다.
- 첫 관측과 교신 완료 뒤에 모두 음파를 다시 보낼 수 있다. 음소거에서도 막대와 음 이름으로 교신을 끝낼 수 있다. 브라우저를 다시 열면 관측과 응답을 이어갈 수 있다.
