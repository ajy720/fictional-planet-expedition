# 에리드 · 반향

## 항로와 도착 장면

- `지구 기준 · 에리다누스자리 40 항성계까지 약 16광년`을 표시한다. 에리드 관측 장면은 작품의 반향 감각을 바탕으로 재현한다.
- 조종석에는 낮고 긴 관측창과 옅은 호박색 내부 빛을 사용한다. 도착 시 거의 어두운 공간에 세 물체를 놓는다. 왼쪽의 낮은 바위, 중앙의 아치, 오른쪽의 기둥을 서로 겹치지 않도록 배치한다.

## 조작과 상태

1. `음파 보내기`를 누르면 화면 아래 중앙에서 얇은 파면이 퍼진다. `반향 대기 중`을 표시하고 한 회차가 끝날 때까지 버튼을 잠근다.
2. 가까운 물체부터 실제 화면 경과 0.5초·1.0초·1.5초에 반향을 한 번씩 보여준다. 수신마다 계기판의 반향 개수와 감지한 물체를 갱신한다. 윤곽선은 2.0초 동안 서서히 사라진다. 색과 함께 실루엣으로 물체를 구분한다. 소리가 켜져 있으면 같은 순간에 짧은 반향음을 재생한다.
3. 세 번째 반향이 돌아오면 `반향 3/3 · 바위, 아치, 기둥`을 표시하고 `탐사 기록 보기`를 연다. 새 음파는 앞선 회차의 마지막 윤곽이 사라진 뒤인 3.5초부터 보낼 수 있다.
4. 기록에는 `음파를 보내 바위, 아치, 기둥의 윤곽을 확인했다.`를 남긴다.

- 반향 도착 시간은 체험용 지연이다. 공간 모델의 미터 거리나 에리드 대기의 음속을 화면에 표시할 경우 별도 근거가 필요하다. 현재 설계의 계기판은 순서와 물체명만 보여준다.
- 모션 감소 모드에서는 파면 대신 반향 도착 순간에 정지 윤곽을 표시한다. 음소거 상태에서도 화면으로 같은 물체, 순서, 완료 상태를 확인할 수 있다.

## 검수

- 음파를 보내기 전에는 물체의 이름과 윤곽이 보이지 않는다. 음파 한 번으로 반향이 0.5초 간격으로 세 번 도착한다.
- 음소거에서도 세 번째 반향이 도착하면 기록 버튼이 열린다. 재발사해도 완료 상태와 저장할 결과가 중복되지 않는다.
