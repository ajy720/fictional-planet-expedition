# 상상 속 행성까지 · 구현 명세

[기획안](../references/project-plan.md)과 [조별 피드백](../references/group-feedback.md)을 바탕으로 작성한다. [UI와 디자인 톤](ui-design.md)에서 시각 참고 자료를 확인할 수 있다. 웹은 B612부터 일곱 천체를 탐사하는 흐름, 목적지별 관찰, 기록 저장과 재방문, 마지막 지구 장면을 제공한다.

## 공통 문서

- [공통 흐름과 상태](flow.md) · 화면 전환, 비행, 지구 돌아보기, 탐사 기록, 오류 복구
- [지구 인트로](stages/earth.md) · 지구에서 태양계까지 이어지는 첫 항로와 B612 이후 항성계 관측
- [UI와 디자인 톤](ui-design.md) · 화면 구성, 공통 조작, 시각·음향 기준
- [화면 문구 목록](ui-copy.md) · 현재 문구, 표시 조건, 한영 전환 설계
- [결정 사항](decisions.md) · 사용자 확인 사항과 검토할 제안

## 목적지별 문서

| 천체 | 작품 | 핵심 경험 |
| --- | --- | --- |
| [B612](stages/b612.md) | 어린 왕자 | 소행성 주위를 둘러보며 장미를 찾고 유리 덮개를 씌운다. |
| [판도라](stages/pandora.md) | 아바타 | 같은 숲의 낮과 밤을 비교한다. 항로에서는 신호의 왕복 지연을 관측한다. |
| [아드리안](stages/adrian.md) | 프로젝트 헤일메리 | 대기에서 샘플을 채취하고 확대해 미생물을 관찰한다. |
| [에리드](stages/erid.md) | 프로젝트 헤일메리 | 어둠 속에 음파를 보내 반향이 그려내는 물체의 윤곽을 관찰한다. |
| [아라키스](stages/arrakis.md) | 듄 | 소금 평원과 집수조를 관측하고 도착 후 남은 물을 비교한다. |
| [밀러](stages/miller.md) | 인터스텔라 | 현지와 지구 시계의 흐름을 비교하고 출발 시점을 고른다. |
| [타투인](stages/tatooine.md) | 스타워즈 | 시간에 따라 두 해가 지고 그림자가 달라지는 모습을 관찰한다. |

각 스테이지 문서는 진입 상태, 조작, 피드백, 완료 조건, 기록, 검수 시나리오를 정의한다. 수치와 연출은 [결정 사항](decisions.md)의 확정 여부를 따른다.
