# 공통 흐름과 상태

## 처음부터 마지막 지구까지

1. 시작 화면에서 `소리와 함께 시작` 또는 `조용히 시작`을 누른다. 두 선택 모두 지구 인트로로 이어진다.
2. 지구 인트로에서 스크롤로 지구 궤도에서 태양계 외곽까지 이동한다. 스크롤 끝점에 도달하거나 마지막 구간에서 `B612로 출발`을 누르면 같은 카메라 자세에서 B612로 자동 비행한다.
3. 두 번째 항로부터는 현재 천체의 근접 시점에서 출발한다. 스크롤로 시점을 멀리 옮겨 주변 천체와 항로를 보고, 항로 조망의 끝에서 같은 카메라 자세로 자동 항해를 시작한다. `이전 시점`과 `다음 시점`으로도 같은 경로를 이동한다.
4. 도착 후 목적지별 관찰을 수행한다. 완료 조건을 만족하면 `탐사 기록 보기`가 열린다. 버튼을 누르면 결과를 기록하고 탐사 기록 화면을 연다. B612 기록에서는 `가까운 항성계 보기`를 열 수 있다.
5. 기록을 확인한 뒤 `다음 목적지 선택`을 누른다. 목적지 선택 화면에서 `추천 항로`의 순서는 판도라 → 아드리안 → 에리드 → 아라키스 → 밀러 → 타투인이다. 이 순서에서 기록이 없는 첫 목적지에 추천을 표시한다. 지구와 일곱 천체를 한 3D 공간에서 조망하고, 천체를 선택하면 현재 위치와 목적지를 잇는 항로와 작품명·거리 기준을 확인할 수 있다. `이 천체로 이동`을 누르면 현재 천체의 근접 시점으로 들어간다. 지구 인트로는 첫 여정에서 한 번 본다.
6. 일곱 번째 기록을 열면 기록 화면의 주 행동을 `마지막 지구 돌아보기`로 바꾼다. 인트로 첫 구도의 지구를 보여준 뒤 카메라가 물러나며 푸른 점으로 전환한다. 점이 남으면 기획안의 질문을 표시한다. 모션 감소 설정에서는 두 정지 프레임을 순서대로 보여준다. `이 작은 점에 함께 사는 우리는 서로를 어떻게 대하고 싶은가?` 아래 `탐사 기록 보기`는 일곱 기록의 목록으로 이어진다. 기록에서 `다음 목적지 선택`으로 다시 비행할 수 있다.

## 상태 전환

| 상태 | 진입 | 전환과 복귀 |
| --- | --- | --- |
| 시작 | 사이트 진입 | 새 여정의 소리 선택 → 지구 인트로. 저장된 상태가 있으면 이어서 탐사 → 직전 상태 |
| 지구 인트로 | 새 여정에서 소리 선택 | 스크롤 끝점 또는 마지막 구간의 출발 버튼 → B612 자동 비행. 지구 돌아보기 → 관측 오버레이 |
| 목적지 선택 | 탐사 기록에서 다음 목적지 선택 | 3D 항로에서 천체 선택 → 경로와 정보 확인 → 이동 버튼으로 출항 관측. 닫기 → 진입한 화면 |
| 출항 관측 | B612 완료 이후 목적지 확정 | 현재 천체 근접 → 주변 천체 → 항로 조망 → 자동 항해. 취소 → 선택한 천체가 표시된 항로 |
| 비행 | 출발 신호가 한 번 처리됨 | 마지막 프레임과 도착 장면 준비 → 도착. 지구 돌아보기 → 관측 오버레이. 일시정지 → 같은 카메라 자세 유지 |
| 도착 | 경로 종료와 장면 준비 완료 | 목적지별 완료 조건 충족 → 기록 보기 활성화. 기록 보기 → 기록 저장 후 탐사 기록 |
| 탐사 기록 | 해당 천체 결과 저장 | 목적지 선택. B612 기록에서는 가까운 항성계 보기, 7곳 완료 시 마지막 지구 장면도 접근 가능 |
| 전체 기록 | 마지막 지구 장면에서 탐사 기록 보기 | 개별 기록 보기, 다음 목적지 선택, 마지막 지구 다시 보기 |
| 마지막 지구 | 일곱 기록을 채운 뒤 마지막 지구 돌아보기 | 탐사 기록 보기 → 일곱 기록 목록. 목록에서 목적지를 다시 선택하거나 마지막 지구 장면 다시 열기 |

### 출항과 자동 비행

- 출항 관측에 들어가면 현재 천체의 근접 시점을 표시한다. 스크롤에 맞춰 같은 3D 공간에서 카메라가 물러나며 주변 천체가 시야에 들어온다. 위로 스크롤하면 같은 경로를 따라 가까워진다.
- 스크롤 구간은 뷰포트 높이의 2배이며 근접, 주변 천체, 항로 조망으로 나뉜다. 이전·다음 시점 버튼은 구간 경계로 이동한다. 모션 감소 상태에서는 구간별 정지 프레임을 제공한다. 끝점의 카메라 위치와 시선에서 자동 항해를 시작한다.
- 자동 비행이 시작되면 스크롤로 항로 진행도를 바꾸는 동작은 종료된다. `일시정지`와 `계속 비행`을 토글한다. 비행과 스테이지의 시간 기반 조작은 탭이나 창이 비활성인 동안 시간을 멈춘다. 확인창이 열린 동안도 현재 시간과 조작 위치를 유지한다.
- 첫 항로의 `지구 궤도` → `달 접근` → `태양계`는 한 카메라 경로로 이어지는 스크롤 구간이다. 그 다음 `B612 순항` → `B612 접근` → 도착을 자동 재생한다. 시점은 [B612 문서](stages/b612.md)를 따른다.
- 두 번째 항로부터는 `{출발 천체} 이탈` 0% → `항로 순항` 25% → `{목적지} 접근` 70% → 도착 100%로 진행한다. 시간은 아래 표, 주요 연출은 목적지 문서를 따른다.
- 목적지 선택 시 장면 로드를 시작한다. 첫 B612는 인트로에 들어갈 때 로드를 시작한다. 비행의 마지막 프레임과 장면 준비가 모두 끝나면 도착한다. 준비 중에는 접근의 마지막 프레임과 `관측 장면을 불러오는 중`을 유지한다. 핵심 장면 로드 오류에는 `다시 불러오기`와 `출항 준비로 돌아가기`를 제공한다. 첫 항로의 복귀 위치는 인트로의 마지막 구간 시작점이다.
- 모션 감소 설정에서는 각 단계의 정지 화면을 보여준다. `다음 비행 단계`를 누를 때마다 다음 노드의 첫 프레임을 표시하고 마지막 단계에서 도착한다.

### 항로별 자동 비행 시간

지구에서 B612로 가는 첫 자동 비행은 8초다. 이후 항로의 재생 시간은 3D 항로 배치의 상대 길이를 기준으로 10–26초로 정한다. 긴 항로는 목표가 먼 점으로 남는 순항 구간에 더 많은 시간을 쓴다. 표의 단위는 연출 초다.

| 출발지 / 목적지 | B612 | 판도라 | 아드리안 | 에리드 | 아라키스 | 밀러 | 타투인 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| B612 | · | 11 | 15 | 18 | 21 | 24 | 26 |
| 판도라 | 11 | · | 10 | 15 | 18 | 20 | 23 |
| 아드리안 | 15 | 10 | · | 11 | 16 | 17 | 21 |
| 에리드 | 18 | 15 | 11 | · | 11 | 15 | 18 |
| 아라키스 | 21 | 18 | 16 | 11 | · | 14 | 14 |
| 밀러 | 24 | 20 | 17 | 15 | 14 | · | 12 |
| 타투인 | 26 | 23 | 21 | 18 | 14 | 12 | · |

출항 조망의 마지막 구간에서 항로의 깊이 축척을 넓힌다. 목적지는 화면상 같은 방향에서 작은 점으로 줄어들고, 자동 항해가 시작되면 카메라가 그 점을 계속 바라보며 접근한다. 멀리서는 목표 표시를 제공하고 천체의 윤곽이 드러나면서 표시를 옅게 한다. 일시정지, 지구 돌아보기, 통신 오버레이, 비활성 탭에 머문 시간은 재생 시간에 포함되지 않는다.

### 항로와 거리 표기

- 항로에는 실제 출발 천체와 목적지 이름을 함께 표시한다. 예를 들어 `B612 → 판도라`. 출발 천체가 바뀌어도 목적지의 지구 기준 거리는 같은 값이다.
- 실재하는 항성의 관측 거리는 `지구 기준 · {항성}까지 약 {값}광년`으로 표시한다. 이 수치는 거리 카드의 참고 정보다. 비행 화면은 상단 노드로 항로 단계를 표시하고 계기판에 `항해 시간 {second}초`를 표시한다.
- B612와 타투인은 `거리 미상 · 가상 항로`, 밀러는 `작품 속 웜홀 경로`, 아라키스는 `원작 기준 모항성 · 카노푸스`로 표시한다.
- 지구·달·태양계 축척, 항성의 관측 거리, 작품 설정과 각 스테이지의 연출 수치는 [UI 거리·시간 표기](ui-design.md#거리와-시간-표기)에 맞춰 읽을 수 있게 한다.

## 지구 돌아보기

| 시점 | 시각 연출과 문구 |
| --- | --- |
| 지구 인트로의 달 접근 | 카메라가 지구 방향으로 전환된다. 대륙과 구름이 남은 작은 원반을 보여준다. |
| 지구 인트로의 태양계 구간 | 지구가 작은 원반에서 점으로 줄어든다. 시야에서 식별할 수 있도록 지구 위치에 라벨을 붙인다. |
| 첫 B612 자동 비행 | 따뜻한 빛 띠 안에 작은 푸른 점을 배치한다. `보이저 1호 사진을 참고한 연출`을 표시한다. |
| 다른 항로의 비행 | 항법 화면에 지구 방향을 뜻하는 푸른 점을 보여준다. 위치를 알 수 없는 천체를 지날 때는 `지구 방향 · 항법 연출`로 표시한다. |
| 각 탐사 직후 | 현재 천체 기록 옆에 푸른 점을 둔다. `지구 돌아보기`를 누르면 항법 화면을 열고 기록으로 돌아올 수 있다. |
| 일곱 곳을 모두 탐사 | 다른 계기 정보가 사라지고 푸른 점과 질문이 남는다. 기록 목록에서 관찰 결과를 다시 읽을 수 있다. |

- 첫 항로의 `지구 돌아보기`는 달 접근부터 제공한다. 인트로에서는 스크롤 진행도와 카메라 자세를 저장하고 스크롤 입력을 잠근다. 자동 비행에서는 경로 시간, 카메라 자세와 재생 여부를 저장하고 비행 시간을 멈춘다. 관측 오버레이와 판도라 통신 화면은 한 번에 하나만 연다.
- `항로로 돌아가기`를 누르거나 오버레이를 닫으면 저장한 프레임과 진행도를 복원한다. 스크롤 구간에서는 다시 입력을 받고 자동 비행에서는 이전 재생 여부를 따른다. `Esc`는 해당 오버레이를 닫으며 포커스를 트리거 버튼으로 돌린다.
- 탐사 기록에서 연 경우 `기록으로 돌아가기`로 복귀한다. 열기와 닫기는 기록 내용과 완료 개수를 바꾸지 않는다.

## 완료 기록과 재방문

- 천체 기록에 이름, 작품, 거리 기준과 출처, 가장 최근 완료한 관찰 결과를 표시한다. 바로 아래에 방금 본 장면에 대한 질문이나 비교 설명과 출처를 둔다. 작품 설정이나 체험용 재현에 해당하는 표기는 기록을 다시 열 때도 결과와 함께 보여준다. 완료 개수는 서로 다른 천체의 기록 개수다. 항로 진입, 도착, 장면 조작만으로는 개수가 오르지 않는다. 같은 방문의 저장 요청이 반복되어도 기록은 하나다.
- 완료한 천체를 3D 항로에서 선택해 다시 이동할 수 있다. 선택 정보의 `기록 보기`는 저장된 기록을 열고 같은 천체가 선택된 항로 화면으로 복귀한다. 현재 천체는 `현재 위치`로 표시하고 다른 천체를 탐사한 뒤 다시 선택할 수 있다.
- 출발 천체는 최근 기록을 저장한 천체다. 이전 기록을 읽는 동안 출발 천체는 유지된다. 재방문에서 기록을 저장하면 출발 천체와 그곳의 최신 결과가 갱신되고 완료 개수는 유지된다.
- 전체 기록은 최초 완료 순서로 정렬하고, 개별 기록을 읽으면 목록으로 돌아올 수 있다. 첫 방문과 재방문에서의 완료 화면은 동일한 조작을 제공한다.
- 아라키스는 경로별 결과를 누적한다. 첫 경로를 기록하면 탐사가 완료된다. 다른 천체에서 재비행해 두 번째 경로를 기록하면 선택 사항인 비교가 열린다. 일곱 곳을 모두 탐사했을 때도 같은 규칙을 적용한다.
- 화면에 활성화된 비행이나 탐사를 종료하려면 `탐사 중단` 후 확인한다. 첫 B612 방문에서는 인트로 마지막 구간의 시작 위치로, 이후 항로는 해당 출항 관측 시작점으로 돌아간다. 완료 기록을 초기화하는 `새 여정`은 시작 화면에서 기존 기록이 있을 때 초기화 확인 후 시작한다.

### 저장과 재개

- 같은 브라우저에서 이어서 볼 수 있도록 소리 설정, 마지막 완료 천체, 최초 완료 순서, 천체별 기록, 현재 화면과 조작을 하나의 저장본에 담는다. 저장본에는 형식 버전을 포함한다. 현재 목적지의 기록 저장과 완료 개수 갱신은 같은 저장으로 처리한다.
- 장면 진입, 선택, 완료, 패널 열기·닫기마다 저장한다. 스크롤·카메라 이동과 타이머는 조작 중 250ms마다 최신 위치를 기록하고, 페이지가 숨겨지거나 닫힐 때 마지막으로 표시한 값을 저장한다. 저장소를 사용할 수 없으면 현재 화면에서 탐사를 계속할 수 있게 하고 `이 브라우저에 탐사를 저장할 수 없습니다`를 표시한다.

| 저장 당시 화면 | 복원하는 항목 |
| --- | --- |
| 지구 인트로 / 출항 관측 | 현재 구간과 스크롤 진행도, 출발지와 목적지 |
| 자동 비행 | 출발지, 목적지, 경로 경과 시간, 현재 단계, 사용자 일시정지 여부 |
| 지구 돌아보기 / 가까운 항성계 / 판도라 통신 | 이전 화면의 위치와 재생 상태, 열었던 패널, 통신 경과와 수신 단계 |
| B612 / 판도라 | B612 궤도 카메라, 바오밥 싹과 장미 덮개 상태, 판도라 조명·야간 관찰 여부, 숲의 시선 각도와 궤도 비교·확대 상태 |
| 아드리안 / 에리드 | 아드리안의 항로 필터·페트로바 선 추적·채취 및 확대 상태, 에리드의 반향 진행과 입력한 응답 |
| 아라키스 / 밀러 / 타투인 | 아라키스 수트 점검·경로·이동 시간·관측 진행·사진·물통 확인, 밀러의 체류 시간과 그에 따른 파도 위치, 타투인 일몰 구간과 궤도 전환 위치 |
| 선택 / 기록 / 마지막 지구 | 화면, 항로에서 선택한 천체나 열어 본 기록, 마지막 완료 천체 |

- 사이트를 다시 열면 시작 화면을 표시한다. 유효한 저장본이 있으면 `이어서 탐사`를 제공한다. 누르면 저장한 화면과 위치를 복원한 뒤, 그 화면에서 실행 중이었던 비행·시계·조작 애니메이션을 자동 재개한다. 사용자가 일시정지한 비행과 오버레이 뒤에 멈춰 있던 비행은 멈춘 채로 복원한다. 시간은 복원 후 화면을 보고 있는 시점부터 더한다.
- 형식을 읽을 수 없는 저장본은 시작 화면에서 `이전 탐사를 열 수 없습니다`와 `새 여정`을 표시한다. 복원한 장면의 에셋을 불러오지 못하면 재시도할 수 있게 저장본과 목표 화면을 유지한다.
- 복원은 저장한 결과 상태부터 렌더링한다. 재개 이후 발생한 전환·효과음만 실행하며 기록은 방문별 한 번 저장한다. 사용자가 소리를 켠 상태에서 재개하면 환경음과 음악은 복원한 장면부터 재생한다.

## 공통 검수

1. 새 여정의 첫 목적지는 B612다. B612 기록 직후 판도라가 추천되며 나머지 여섯 곳 중 임의의 천체를 선택할 수 있다. 판도라와 에리드를 완료한 상태에서는 아드리안을 추천한다.
2. A 완료 후 B를 선택하면 비행 화면은 `A → B`를 표시한다. 목적지가 실재 항성을 기준으로 할 경우 별도 필드에 `지구 기준`을 표시한다.
3. 출항 스크롤을 내리면 현재 천체가 작아지며 주변 천체가 들어온다. 위로 스크롤하면 카메라가 같은 경로로 돌아온다. 마지막 프레임에 닿으면 같은 자세에서 자동 항해를 한 번 시작한다.
4. 비행 중 돌아본 뒤 복귀하면 같은 항로 위치와 재생 상태가 복원된다. 다른 브라우저 탭을 보고 돌아와도 구간을 건너뛰지 않는다.
5. 여섯 개 기록으로는 마지막 지구 장면이 잠겨 있고, 일곱 번째 기록 직후 진입 버튼이 열린다.
6. 데스크톱에서 음소거, 키보드, 모션 감소 중 어느 조건에서도 같은 기록과 마지막 장면까지 도달할 수 있다.
7. 아라키스의 첫 경로만 지나도 완료 수에 포함된다. 다른 천체에서 아라키스로 재비행해 두 번째 경로를 기록하면 완료 수는 그대로이고 두 경로가 나란히 표시된다.
8. 아라키스를 일곱 번째로 탐사한 경우 엔딩을 연 뒤 기록 목록에서 완료한 다른 천체로 재비행할 수 있다. 그곳을 마친 뒤 아라키스로 다시 출발할 수 있다.
9. 자동 비행과 밀러에서 페이지를 닫고 열면 `이어서 탐사` 후 저장한 프레임과 시간부터 이어진다. 닫혀 있던 시간은 반영되지 않는다. 저장 전 사용자 일시정지 상태도 확인한다.
10. B612에서 판도라로 향할 때는 11초, 타투인으로 향할 때는 26초다. 두 항로 모두 목적지가 먼 점에서 시작해 접근 중 같은 위치의 천체로 커진다.
