# 결정 사항

## 확인한 방향

| 항목 | 결정 | 적용 문서 |
| --- | --- | --- |
| 첫 항로 | 첫 탐사 목적지는 B612로 고정한다. B612 탐사 후 나머지 여섯 곳은 순서 없이 선택한다. | [공통 흐름](flow.md) |
| 출발 조작 | 사용자가 스크롤로 임계점을 넘겨 출발 신호를 보낸다. 이후는 자동 비행이다. | [공통 흐름](flow.md) |
| UI와 조종석 | 차분한 관측 화면을 기본으로 삼는다. 항로에 따라 관측창과 조명이 바뀐다. | [UI와 디자인](ui-design.md) |
| 항로 연결 | 탐사를 마친 천체에서 다음 천체로 출발한다. | [공통 흐름](flow.md) |
| 기록과 엔딩 | 각 천체 탐사 직후 해당 기록을 보고, 일곱 곳의 탐사를 마치면 마지막 지구 장면을 연다. | [공통 흐름](flow.md) |
| 목적지 범위 | 일곱 천체에 각각 핵심 도착 조작 하나를 두고, 완료 조건과 관찰 결과를 명시한다. | [목적지별 명세](README.md#목적지별-문서) |
| 판도라 통신 | 조종석에서 지구 중계국에 발신을 요청하고, 지구↔판도라의 지연을 별도 시계에 표시한다. | [판도라](stages/pandora.md) |
| 아라키스 비교 | 첫 방문에서 한 길을 지나고, 나중에 아라키스로 실제 재비행해 다른 길을 지나면 비교한다. | [아라키스](stages/arrakis.md) |
| 재방문 | 완료한 천체도 목적지 목록에서 다시 선택할 수 있다. 아라키스는 한 경로만 지나도 완료로 집계된다. | [공통 흐름](flow.md) |
| 밀러 체류 | 두 시계가 자동으로 흐르고 사용자가 출발 버튼을 눌러 체류를 끝낸다. | [밀러](stages/miller.md) |
| B612 장미 | 사용자가 방향 힌트 없이 소행성 주위를 직접 둘러본다. | [B612](stages/b612.md) |
| 첫 비행의 연결 | 지구에서 달과 태양계까지 한 카메라 경로로 물러나고, 마지막 프레임부터 B612로 자동 비행한다. 가까운 항성계는 B612 기록 이후에 보여준다. | [지구](stages/earth.md) |
| 제출 기기 | 데스크톱을 대상으로 제작하고 검수한다. 모바일은 완성 이후 검토한다. | [UI와 디자인](ui-design.md) |
| 3D 스타일 | 모든 천체를 저폴리로 제작하고 조명과 질감은 작품마다 바꾼다. | [UI와 디자인](ui-design.md) |
| 재개 | 완료 기록과 진행 중인 화면·조작 위치를 저장한다. 시작 화면의 `이어서 탐사`가 복원과 자동 재생을 시작한다. | [공통 흐름](flow.md#저장과-재개) |
| 비행 시간 | 8–15초 안에서 출발지와 목적지 조합마다 연출용 시간을 정한다. | [공통 흐름](flow.md#항로별-자동-비행-시간) |
| 아라키스 거리 | `원작 기준 모항성 · 카노푸스`를 표시한다. | [아라키스](stages/arrakis.md) |
| 음향 | 작품 OST의 사용 가능 여부를 먼저 확인한다. 사용이 가능한 곳은 OST를 쓰고, 나머지에는 천체별 별도 배경음악을 환경음과 함께 적용한다. | [UI와 디자인](ui-design.md#입력과-오디오) |

## 검토할 구현 초안

| 항목 | 제안 | 적용 범위 |
| --- | --- | --- |
| 출발 임계점 | 첫 항로는 지구 인트로 끝에 도달하면 바로 출항한다. 이후 출항 대기에서는 뷰포트 높이의 75%만큼 스크롤하면 출항한다. 두 경우 모두 키보드로 같은 결과에 도달한다. | 공통 출항 |
| 입력 | 데스크톱에서 마우스와 키보드 각각으로 탐사 완료까지 같은 결과를 얻을 수 있게 한다. | 공통 UI |
| 저장 | 같은 브라우저에서 최신 상태를 복원한다. 시간 기반 조작은 마지막 저장 위치부터 재개한다. | 탐사 기록, 재방문 |
| 연출 수치 | 42개 항로의 초 단위 배정, 카메라 각도, 애니메이션 시간, 색상, 모델 복잡도와 스테이지 수치는 첫 구현의 기준값으로 제안한다. | [공통 흐름](flow.md), [UI와 디자인](ui-design.md), 각 스테이지 |

곡 후보와 사용 확인 결과는 에셋 선정 단계에서 기록한다.
