# UI와 디자인 톤

## 시각 방향

천체와 환경을 화면 전체에 배치한다. 관측 대상 가까이에 조작을 표시하고, 비행 거리·시간과 일시정지 같은 공통 정보는 화면 가장자리에 둔다. 텍스트의 위계는 크기, 여백, 밝기, 밑줄로 표시한다. 가는 연결선은 조작이 어느 대상을 가리키는지 나타낸다.

- 화면 가장자리의 수치, 상태와 조작은 헬멧 시야 안쪽으로 완만하게 기울인다. 글자 가장자리에 은은한 빛 번짐을 두고, 마우스를 움직이면 시야를 따라 조금씩 이동한다. 포인터가 화면을 벗어나면 기준 위치로 돌아간다. 조작 위에서는 움직임을 멈추며, 모션 감소 설정에서는 포인터 반응을 끈다. 상단 공통 헤더와 출처·확인 패널은 평면으로 표시한다.

- [About Luca 참고 화면](../references/about-luca-webgl.jpg)의 원근감과 공간 속 타이포그래피를 적용한다. B612 근접 화면의 제목은 다른 천체 표면처럼 카메라에 따라 움직이고 지형에 가려진다. 행성 제목은 관측 장면에 놓고, 장미·탐사선·사막 경로 등의 조작은 각 대상의 3D 위치를 따라간다. 순항에서는 가까운 미립자가 빠르게 스친다.
- [Byotōne 참고 화면](../references/byotone-sound-entry.jpg)의 두 입장 선택과 연결 노드를 적용한다. 두 입장 조작을 첫 화면에서 같은 강조 수준의 텍스트로 표시한다. 비행 노드는 지나온 구간, 현재 구간, 남은 구간을 형태와 텍스트로 구분한다.
- [창백한 푸른 점 참고 사진](../references/pale-blue-dot.jpg)의 넓은 여백과 좁은 빛 띠를 돌아보기 장면에 적용한다. 푸른 점의 위치는 지구 라벨과 연결하고, 엔딩에서는 주변 정보의 밝기를 낮춰 점과 질문이 먼저 보이게 한다. [NASA/JPL-Caltech 원본 재처리본](https://science.nasa.gov/photojournal/pale-blue-dot-revisited/)

## 3D 장면 제작

- 천체와 주요 사물은 저폴리 형태를 사용한다. 지구의 대륙과 구름, B612의 암석과 장미, 판도라의 잎처럼 멀리서도 구별할 실루엣부터 만든다. 천체 원반은 32×16 분할 구체를 시작점으로 삼고, B612 암석은 면이 드러나는 320–1,280 삼각형을 기준으로 한다. 구형 천체의 실루엣은 부드럽게, 가까운 지형은 면과 가장자리가 읽히게 조명과 법선을 조정한다.
- 지구–달은 푸른 대기와 차가운 회색 암석, B612는 거친 암석과 붉은 장미, 판도라는 잎의 청록 발광, 아드리안은 탁한 대기와 투명 시료, 에리드는 가느다란 반향 윤곽, 아라키스는 건조한 모래와 짙은 그늘, 밀러는 얕은 물의 흐린 반사, 타투인은 노을과 그림자에 집중한다. 고해상도 텍스처보다 색면, 러프니스, 조명 방향과 강도로 차이를 만든다.
- 도착 시 처음 보여줄 관측 대상이 화면의 중심 60% 안에 들도록 한다. 장미 탐색 장면은 장미 대신 소행성 전체가 처음 프레임에 든다. 판도라와 타투인은 같은 위치에서 환경 변화를 비교한다. 마우스 움직임에 반응하는 작은 시점 변화는 조작에 포인터를 올리면 멈춘다.

### 관측 시점 전환

- 상호작용으로 시점이 바뀔 때는 버튼을 누른 순간의 카메라 위치, 시선 방향, 확대 상태에서 시작한다. 시선과 이동 속도가 부드럽게 변하도록 이어서, 관측 대상과 주변 지형의 관계를 따라갈 수 있게 한다.
- 카메라 경로는 천체 표면과 주요 물체를 피해 설계한다. 세부 관측을 닫거나 둘러보기로 돌아가면 가능하면 같은 경로를 거슬러 직전 위치·각도·확대 상태를 복원한다.
- 이동이 끝난 뒤 도착 시점의 조작을 활성화한다. 판도라의 낮·밤처럼 같은 구도를 비교하는 조작은 카메라 이동을 발생시키지 않는다. 모션 감소에서는 전환을 생략하거나 고정 프레임으로 보여주고 같은 조작을 제공한다.
- 각 스테이지를 검수할 때 서로 다른 각도와 확대 상태에서 진입과 복귀를 확인한다. 시작·끝에서 시점이 튀거나 이동 중 카메라가 지형을 관통하는지 살핀다. [B612 적용 예](stages/b612.md#조작과-상태)

## 화면 구조

| 영역 | 데스크톱 배치 |
| --- | --- |
| 상단 | 왼쪽에 화면·천체 이름, 가운데 비행 단계, 오른쪽에 소리와 출처 |
| 관측창 | 전체 화면을 3D 장면에 사용한다. 관측 대상 옆에 텍스트와 행동을 투영한다. |
| 하단 | 왼쪽에 거리·시간, 가운데에 상태와 진행 안내, 오른쪽에 공통 보조 행동을 표시한다. |
| 목적지 선택 | 3D 천체와 항로를 함께 표시한다. 목적지 선택과 항로 조망에서 천체 이름은 B612 관측 타이틀과 같은 방식으로 천체 근처의 3D 공간에 배치한다. 선택 시 거리와 출항 조작은 천체 주변의 빈 공간에 나타난다. 주변에 배치할 공간이 부족하면 화면 하단을 사용한다. |
| 탐사 기록 | 관측 장면의 어두운 여백에 기록을 펼친다. 전체 기록은 방문 순서대로 한 줄씩 보여준다. |

아래 화면별 항목을 기본 노출한다. 활성 상태에서 수행할 수 있는 행동을 화면에 둔다.

| 화면 | 제목과 계기판 | 주요 행동 |
| --- | --- | --- |
| 시작 | `상상 속 행성까지`와 지구의 주광면 | `소리와 함께 시작`, `조용히 시작`. 저장된 여정이 있으면 `이어서 탐사`, `새 여정` |
| 지구 인트로 | 장면 이름, 현재 축척과 수치, 출처 | `이전 구간`, `다음 구간`. 달 접근부터 `지구 돌아보기`, 마지막에 `B612로 출발` |
| 목적지 선택 | 지구와 일곱 천체, 현재 위치, 완료 개수. 세미나 항로를 점선으로, 선택한 목적지까지의 항로를 실선으로 표시한다. 배치는 가상 항로의 시각화다. | 천체를 골라 작품과 거리 기준을 확인한 뒤 `판도라로 출항`처럼 목적지명이 들어간 조작. 완료 천체는 `기록 보기`도 제공한다. |
| 출항 관측 | `{출발 천체} → {목적지}`, 거리 기준, 근접에서 항로 조망으로 바뀌는 단계 | 스크롤, `이전 시점`, `다음 시점`, `취소`. 판도라 항로에서는 통신 버튼을 제공한다. |
| 비행 | 항로 제목, 연결 노드, 목적지 거리 기준, 항해 시간, 먼 목적지의 추적 표시 | `일시정지` / `계속 비행`, `지구 돌아보기`, `탐사 중단`. 판도라에서는 통신 버튼을 유지한다. |
| 도착 | 천체명과 현재 관측 상태. 조작 후 핵심 변화와 결과 문구 | 스테이지 조작, 완료 시 `탐사 기록 보기`, `탐사 중단` |
| 탐사 기록 | 관찰 결과와 현실 비교, 작품, 거리 기준, 출처, 완료 개수와 지구 점 | `지구 돌아보기`, `다음 목적지 선택`. B612 기록에서 `가까운 항성계 보기`, 7곳 완료 시 `마지막 지구 돌아보기` |
| 전체 기록 | 일곱 기록을 최초 완료 순서로 표시 | `기록 보기`, `다음 목적지 선택`, `마지막 지구 다시 보기` |
| 마지막 지구 | 인트로 첫 구도의 지구에서 푸른 점으로 전환한 뒤 질문 한 줄 | `탐사 기록 보기` |

### 연결 노드

상단 노드는 현재 비행 한 건의 구간을 보여준다. 구간 시작 시 노드 상태를 전환한다. 완료 노드는 따뜻한 밝은 테두리, 현재 노드는 채운 원과 아래 단계명, 남은 노드는 회색 테두리로 표현한다. 각 단계는 표시 순서와 현재 상태가 포함된 목록으로 읽을 수 있게 한다. 탐사 전체의 완료 수는 기록 화면과 목적지 선택 화면에서 `n/7`로 표시한다.

### 거리와 시간 표기

| 분류 | 계기판 표기 | 출처 패널 |
| --- | --- | --- |
| 관측·평균 거리 | `지구–달 평균 거리 384,400 km`, `지구 기준 · 타우 세티까지 약 11.9광년` | 대상과 출처, 표시 단위 |
| 비교 축척 | `지구–태양이 1cm라면 …`, 필요한 장면에 `크기 강조` | 비교식과 사용한 원래 거리 |
| 작품 설정 | `원작 기준 모항성 · 카노푸스`, `작품 속 웜홀 경로` | 작품명과 참고 자료 |
| 거리 미상 | `거리 미상 · 가상 항로` | 작품명과 가상 항로 안내 |
| 체험용 수치 | `이 체험의 물 사용량`, `가상의 관측 시간대`, `시간 압축 재생` | 수치가 의미하는 조건 또는 환산 방식 |

화면 카피의 단위는 `km`, `AU`, `광년`, `년`, `일`, `초`, `mL`를 쓴다. `광년`은 거리, `년`은 시간에 사용한다. 거리·시간 단위와 기준점을 값과 함께 읽을 수 있게 표시한다. 출처와 축척은 별도 패널의 링크에서 확인한다.

- 항로 지도에서는 천체 모형 사이에 여백을 확보한다. `지구 기준 거리 비교`는 가상 항로와 별도로, 지구에서 작품과 연관된 실제 항성까지의 거리를 10배 단위 눈금과 지구–태양 1cm 환산으로 보여준다. 환산 거리는 탐사 기록과 거리 표시에서 서강대부터 여의나루역, 고속터미널역, 성수역, 전주역까지의 대략적인 직선거리에 빗댄다.
- `지구 돌아보기`는 거리 기준이 있는 목적지에서 빛의 편도 이동 시간과 지구의 각지름을 표시한다. 화면의 지구 점을 확대해 상대적인 크기를 비교하고, 거리 미상인 목적지에는 방향 표식을 표시한다.
- 도착 시 천체에 더 가까워진 시점 위로 첫 관측 화면이 서서히 드러난다. 모션 감소 설정에서는 도착 장면으로 바로 전환한다.

## 입력과 오디오

- 공통 버튼과 범위 입력은 HTML 컨트롤로 제공한다. 상태 변경 시 해당 화면의 제목 또는 첫 행동으로 포커스를 옮긴다. 패널은 `Esc`로 닫고 열었던 요소에 포커스를 돌린다. 방향키와 스크롤 제어는 해당 화면이나 컨트롤에 포커스가 있을 때만 적용한다.
- 3D 선택은 장면 속 포인터와 같은 동작을 실행하는 대상을 따라가는 HTML 버튼을 제공한다. 작은 화면에서는 조작을 하단에 표시한다. B612 장미 관찰은 장면에서 장미가 보일 때 두 경로 모두 열리고, 보이기 전에는 카메라 조작만 제공한다.
- 키보드 포커스는 기본적으로 밝은 외곽선으로 표시한다. 아라키스의 두 경로 버튼은 포커스가 있는 경로 이름에 밝고 굵은 밑줄을 표시한다. 도착, 채취 완료, 반향 수신 등 상태가 바뀔 때만 상태를 읽어준다. 밀러의 매초 갱신은 읽기 알림 대신 화면에 두고 출발 시 고정된 값을 읽어준다.
- `prefers-reduced-motion`이 켜지면 순항 입자 흐름, 흔들림과 줌 전환을 줄이고 구간별 정지 프레임을 제공한다. 탐사 수치와 조작 결과는 같은 방식으로 확인할 수 있다.
- `소리와 함께 시작` 또는 소리를 켠 여정의 `이어서 탐사`를 누르면 오디오를 시작한다. 소리 설정은 모든 화면에서 `소리 켜기`와 `소리 끄기`로 바꿀 수 있다. 음소거하면 환경음, 음악, 효과음을 한꺼번에 멈춘다.
- 비행 중에는 공통 엔진음과 항로별 환경음을 섞는다. 도착 시 500ms에 걸쳐 환경음과 음악을 전환한다. 관찰의 시작·완료 효과음은 짧게 재생하고, 모든 변화에 해당하는 상태 문구나 시각 신호를 준다.
- 도착 장면마다 배경음악 한 곡과 환경음 한 트랙을 기본으로 사용한다. 핵심 조작의 효과음은 스테이지 문서를 따른다. 작품 OST는 곡을 고른 뒤 수업 시연과 예정된 웹 제공 방식에서 사용할 수 있는지 확인한다. 확인이 끝난 곡은 사용 범위에 맞춰 적용한다. 사용이 어렵거나 확인이 끝나지 않은 천체에는 직접 제작하거나 사용 조건을 확인한 별도 배경음악을 배정한다.
- 음원을 정하면 천체별로 곡명, 제작자, 사용 조건의 근거와 표시할 크레딧을 출처 패널에 연결한다. 사운드 로드에 실패해도 상태 표시와 조작을 제공한다.

## 오류 화면과 검수

- 3D 장면을 불러오는 동안 이전 장면 또는 정지 이미지를 유지하고 `관측 장면을 불러오는 중`을 표시한다. 장면 로드에 실패하면 다시 불러오기와 이전 안전한 화면으로 복귀하는 버튼을 제공한다.
- WebGL을 사용할 수 없으면 `이 브라우저에서 3D 관측을 시작할 수 없습니다`를 표시한다. 시작 화면에서 3D 없이 열 수 있는 `탐사 소개와 출처`를 제공한다.
- 데스크톱 1440×900과 1280×720을 기준으로 거리, 시간, 행동 문구가 잘리지 않는지 확인한다. 모바일 UI는 제출본 완성 후 검토한다.
- 판도라 숲의 낮, 에리드의 어둠, 아라키스의 밝은 사막에서 계기판을 읽을 수 있어야 한다. 입자와 공간 표식이 주요 대상이나 포커스 표시를 가리지 않는지 확인한다.
